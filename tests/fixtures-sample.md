# 第一章 矩阵

## 一、单项选择题
1. 矩阵 $A$ 可逆的充要条件是（ ）
A. $|A|=0$  B. $|A|\neq 0$  C. $A$ 是方阵  D. $A^T=A$
答案：B
解析：行列式非零。

2. Which are vector spaces? [multi]

- [ ] the unit circle
- [x] polynomials of degree ≤ 2

## 二、判断题
3. 单位矩阵是对称矩阵。

## 三、填空题
4. 二阶单位矩阵的迹为 ____ ，行列式为 ____。

## 四、计算题
6. 求 $\int_0^1 x^2\,dx$。
