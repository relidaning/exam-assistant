## 2026-10-18 — Build exam assistant and import first vault course
Built the app from scratch: a Node server with no build step, a Markdown/JSON importer (plus the exam-import skill), modules per course, answer widgets for each question type, and unit + Playwright e2e tests at desktop and phone sizes. Imported 习思想概论 (737 questions) from the Obsidian vault, which meant hardening `parse-md` for messy notes (glued options, answers with no colon, bare answer lines, zero-width characters). Fill-in grading now ignores punctuation after NFKC normalization but keeps `.` and `-` significant, so `0.5` ≠ `05`.
Home-screen icons differed by device because the only icon was `icon.svg`: iOS/iPadOS can't use an SVG `apple-touch-icon`, so Safari fell back to a page snapshot, while Android used the SVG and masked it. Added `scripts/icons.mjs` (`npm run icons`), which renders `apple-touch-icon.png` (180, full-bleed), `icon-192/512.png` and `icon-maskable-512.png` (artwork kept inside the safe zone). Linked them from `index.html` and the manifest.
Mock exam paper picker: dropped the "Random mix" option (courses with past papers now only offer real papers; courses without any still draw by the exam settings). Papers are listed newest sitting first (date read from names like `2025年4月真题`, `2023-12`, `June 2021`; undated ones last), and each shows "Not taken yet" or its last result (score %, best if higher, right/total, time, when). The newest paper not sat yet is preselected. Also fixed a double tap on "Finish" recording an exam twice (`finalize` in `run.js` now guards against re-entry). One duplicate record from before the fix is still in the data (计算机系统原理, 13015 2026年4月真题, 2026-10-19 02:09).
Loaded web practice for 13015 计算机系统原理: 121 fill-ins (掘金 13015填空题, chapters 1–6, with extra accepted spellings per blank) and 206 名词解释 (掘金 记忆指南, 记忆关键词 kept as `keywords`), all tagged `网络练习` with per-chapter `chapter`. The course now has 444 questions. Raw pages, the converted JSON and a README are in Nextcloud at `lidaning/beijing self-taught exams/13015 计算机系统原理/web-practice/`. Skipped the OCR'd 课后习题 article (wrong answers), paywalled CSDN posts and the unreachable 助学堂 mock papers. The Nextcloud MCP connector returned 401, but WebDAV via curl with `~/.zshrc.local` credentials worked.
Practice: Ctrl/Cmd+Enter now works with nothing entered. It shows the answer and counts as wrong, so the question goes to the mistakes book; open questions go straight to self-grading. Pressing it again moves on. Handled in the fill/calc inputs, the short-answer box and globally for choice questions (`submit({ reveal })` in `run.js`). Added an e2e check.
Option text can now be selected and copied: choice options are focusable `div`s (`selectable()` in `answer.js`, with Enter/Space and letter keys still working) instead of `<button>`s, which block text selection. Finishing a drag-selection doesn't count as picking the option. Answered options are `aria-disabled`.
Self-grading keys: Y / P / N (1–3 still work) for got it / partly / missed it, with a small key hint on each button (hidden on touch screens).
Unfinished rounds moved from each browser's localStorage to a new `sessions` table (one row per course and slot, `GET/PUT/DELETE /api/courses/:id/sessions[/:slot]`, also returned with the course). `data.js` keeps a live copy, saves back 400 ms after a change, sends pending saves before any reload and on page hide (keepalive), and falls back to localStorage if the server can't be reached. Existing browser rounds move up the first time each browser opens the course; when both sides have one, the newer save wins, or the one with more answers for pre-sync rounds. A progress reset now drops rounds too. Tests: API round trip plus an e2e run with 127.0.0.1 and localhost sharing one round. Server restarted.
Practice: a revealed short answer or definition must be self-graded before Next, →, swipe, the question list or Finish move on (button dimmed, a toast and a nudge on the grading row). Star and Re-parse moved from the top bar to a toolbar under the question card, with S and P keys (P stays "Partly" while grading buttons are showing). Starred questions get a gold corner badge in the question list, plus a legend entry. Identical toasts no longer stack. Fixed a pre-existing race where the Settings page's post-import redraw (1.5 s timer) or a slow settings load could draw over whatever page you'd moved to.
